# Проект Web-Telefony

## Обзор

**web-telefony** — это полнофункциональное приложение, предназначенное для обработки телефонных коммуникаций с интеграцией в систему CRM. Оно предоставляет возможности для звонков, управления контактами и обмена сообщениями через веб-интерфейс.

## Подробное описание директории `src/server`

Директория `server` содержит серверные компоненты приложения, включая настройку базы данных, маршрутизацию, аутентификацию и работу с внешними сервисами. Вот подробное описание каждого файла и его роли:

### Основные файлы

- **`index.ts`**: Главная точка входа для Express.js приложения. Настраивает и запускает сервер, управляет промежуточным ПО (middlewares), включая CORS и обработчик ошибок. Также инициализирует маршрутизацию и аутентификацию.

- **`db.ts`**: Настройка и подключение к базе данных с использованием PostgreSQL и `drizzle-orm`. Обеспечивает управление пулами соединений и обеспечивает инициализацию базы данных.

- **`schema.ts`**: Определение схем таблиц базы данных с использованием `drizzle-orm`. Включает в себя описания для пользователей (`users`) и настроек телефонии (`telephonySettings`).

- **`storage.ts`**: Реализует интерфейс для взаимодействия с базой данных, который управляет CRUD операциями для пользователей, контактов и вызовов. Также настраивает хранение сессий через `connect-pg-simple`.

- **`vite.ts`**: Настраивает Vite на сервере для динамического обновления страниц клиента и статического рендеринга страниц.

- **`auth.ts`**: Использует Passport.js для реализации стратегии локальной аутентификации, управляет хэшированием паролей и сессиями пользователей.

### Маршруты

- **`routes/authRoutes.ts`**: Обеспечивает аутентификацию пользователей с помощью маршрутов для входа, выхода и регистрации. Обрабатывает сессии и проверку подлинности на стороне сервера.

- **`routes/callsRoutes.ts`**: Управляет маршрутизацией, связанной с обработкой вызовов. Предоставляет возможности для создания и получения информации о вызовах.

- **`routes/contactsRoutes.ts`**: Оперирует маршрутизацией, связанной с управлением контактами. Отвечает за создание и получение контактов из базы данных.

- **`routes/telephonyRoutes.ts`**: Предоставляет доступ к CRUD операциям, связанным с настройками телефонии пользователя. Осуществляет сохранение и извлечение данных телефонии.

### Сервисы

- **`services/telephonyService.ts`**: Работает с модулями для сохранения и извлечения настроек телефонии для пользователя и их взаимодействия с базой данных.

- **`services/openai.ts`**: Взаимодействует с OpenAI для анализа транскрипций звонков, позволяя проводить анализ настроений и информацию о следующем действии.

- **`services/twilio.ts`**: Интеграция с Twilio для управления голосовыми вызовами, включая создание вызовов, получение статусов и записей.

- **`services/mtt.ts`**: Обеспечивает функции звонков используя сервис MTT, поддерживает управление вызовами и получение записей путем взаимодействия с их API.

- **`services/amocrm.ts`**: Интеграция с AmoCRM, позволяет создавать и управлять контактами и сделками в CRM через API.

### Миграции

- **`migrations/create_calls_table.sql`**: Скрипт SQL для создания таблицы вызовов в базе данных. Определяет ее структуру и поля.

- **`migrations/update_calls_table_add_contact_id.sql`**: Добавляет столбец `contact_id` в таблицу вызовов для поддержки связи вызовов с контактами.

## Модуль аутентификации в `src/server/auth.ts`

Файл `auth.ts` отвечает за обработку аутентификации и управления сессиями в проекте. Он реализует следующие основные функции:

- **Настройка аутентификации с помощью Passport.js**: Используется стратегия локальной аутентификации для проверки имени пользователя и пароля. При попытке входа в систему, если пользователь найден и пароль его совпадает, пользователь успешно аутентифицируется.

- **Хэширование паролей**: Для безопасности пароли хэшируются с использованием алгоритма `scrypt`, прежде чем они будут сохранены в базе данных. Это защитит их в случае, если данные будут скомпрометированы.

- **Сравнение паролей**: Хранящиеся и введенные пароли сравниваются при помощи безопасного метода `timingSafeEqual` для предотвращения атак типа "время побочного канала".

- **Управление сессиями**: Сессии настраиваются с использованием `express-session`, используя секретное окружение для шифрования данных сессии. Сессии используются для хранения состояния аутентификации пользователя.

- **Обработчики маршрутов аутентификации**:
  - **`POST /api/auth/login`**: Обработчик для входа пользователей. Используется `passport.authenticate` для аутентификации запросов пользователей и создания сессий.
  - **`GET /api/auth/user`**: Возвращает информацию о текущем аутентифицированном пользователе, если пользователь прошел проверку. 

Этот модуль интегрируется в приложение Express и обеспечивает многоуровневую систему безопасности, которая защищает ресурсы и данные пользователей вашего приложения.

### Страницы в директории `client/src/pages`

Директория `pages` содержит компоненты страниц, которые определяют различные представления и маршруты внутри клиентской части приложения. Вот подробное описание страниц, присутствующих в этом каталоге:

- **`ai.tsx`**: Страница для взаимодействия с компонентами искусственного интеллекта. Отображает функции ИИ и обеспечивает пользовательское взаимодействие с ними.

- **`auth-page.tsx`**: Страница аутентификации. Управляет процессом входа пользователей в систему, включая ввод учетных данных и их проверку.

- **`calls.tsx`**: Предназначена для работы с вызовами. Включает функции создания нового вызова, просмотра истории вызовов, отображения аналитических данных и взаимодействия с ИИ для получения инсайтов.

- **`contacts.tsx`**: Упрощает управление контактами пользователя, предоставляя доступ к созданию, просмотру и редактированию информации о контактах.

- **`crm.tsx`**: Страница управления CRM. Содержит функции, связанные с действиями по управлению взаимоотношениями с клиентами.

- **`dashboard.tsx`**: Главная панель приложения, обеспечивающая общую статистику и быстрый доступ к основным функциям, таким как последние звонки и добавление новых контактов.

- **`leads.tsx`**: Содержит функции для управления лидами, включая обзор и взаимодействие с потенциальными клиентами.

- **`messengers.tsx`**: Страница взаимодействия с мессенджерами, где пользователи могут управлять и отслеживать сообщения, связанные с CRM и другими платформами.

- **`not-found.tsx`**: Шаблон страницы, отображаемый, когда запрашиваемый маршрут не найден. Используется для обработки ошибок маршрутизации.

- **`profile.tsx`**: Управляет отображением и редактированием информации профиля пользователя.

- **`settings`** - **Директория Настроек**: Содержит подстраницы, связанные с конфигурацией различных аспектов приложения:
  - **`settings.tsx`**: Обзорная страница настроек, дающая пользователям быстрый доступ ко всем параметрам конфигурации.
  - **`settings/crm.tsx`**: Конфигурация и управление настройками CRM.
  - **`settings/database.tsx`**: Управление и настройка параметров базы данных.
  - **`settings/telephony.tsx`**: Настройки, связанные с функциями телефонии в приложении.

## Доступные скрипты

В корневом каталоге вы можете выполнить:

- **`npm run dev`**: Запуск сервера разработки с использованием `tsx`.
- **`npm run build`**: Сборка проекта для продакшен.
- **`npm run start`**: Запуск сервера в продакшен-режиме.
- **`npm run check`**: Проверка типов в проекте с помощью TypeScript.
- **`npm run db:push`**: Отправка последней схемы базы данных в базу данных с помощью Drizzle Kit.

## API Эндпоинты
API-сервер работает на базе маршрута `/api` со следующими подмаршрутами:

- **`/auth`**: Операции, связанные с аутентификацией
- **`/contacts`**: Управление информацией о контактах
- **`/calls`**: Обработка операций вызовов
- **`/telephony`**: Операции телефонной службы

## Возможности клиентской части

- **Главная панель**: Панель управления пользователя для доступа к различным частям приложения.
- **Страница аутентификации**: Аутентификация и управление пользователями.
- **Управление контактами**: Управление и просмотр контактов.
- **Операции вызова**: Интерфейс для совершения и управления вызовами.
- **Страницы настроек**: Доступ к настройкам, связанным с телефонией, CRM и базами данных.
