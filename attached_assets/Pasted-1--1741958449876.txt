1️⃣ Описание проекта
Функционал:

Голосовой ИИ: звонит клиентам, ведет диалог, обрабатывает возражения.
Телефония: интеграция с SIP-провайдерами (Twilio, Zadarma, UIS, МТТ).
Запись данных: интеграция с AmoCRM / Bitrix24 / внутренняя БД.
Прогрев клиентов: автоматические касания через WhatsApp API, email, SMS.
Аналитика звонков: транскрибация (Whisper) + Power BI.
Личный кабинет: управление клиентами, настройка скриптов звонков.
Панель администратора: мониторинг звонков, настройки тарифов.
Оплата подписки: Stripe / CloudPayments.
2️⃣ Архитектура проекта
Компонент	Технология
Голосовой ИИ	Retell API (озвучка) + GPT-4 (диалоги)
Диалоговый ИИ	Rasa (обработка контекста)
Телефония	SIP через Twilio / Zadarma / UIS / МТТ
CRM	Интеграция с AmoCRM / Bitrix24
Прогрев клиентов	WhatsApp API + Email (SendPulse) + SMS (Twilio)
Аналитика	Whisper (Speech-to-Text) + Power BI
Бэкенд	Python (FastAPI, Django) / Node.js
Фронтенд	React.js / Vue.js
База данных	PostgreSQL / MongoDB
Облако	AWS / Yandex Cloud / DigitalOcean
Оплата	Stripe / CloudPayments
3️⃣ Основные функциональные модули
1. Голосовой ИИ (Авто-обзвон)
📌 Задачи:

Получает список номеров из базы.
Делает звонки через SIP.
Озвучивает текст с помощью Retell API.
Ведет диалог на основе GPT-4 + Rasa.
Фиксирует результат звонка в CRM.
📌 Технические требования:

Задержка ответа <1 сек.
Поддержка нескольких языков.
2. Телефония (SIP-интеграция)
📌 Задачи:

Подключение к Twilio, Zadarma, UIS, МТТ.
Поддержка входящих и исходящих звонков.
Запись разговоров.
📌 Технические требования:

Подключение нескольких номеров.
Поддержка Call Tracking.
3. CRM-интеграция
📌 Задачи:

Автоматическое создание контактов.
Запись статуса звонка (успешно, отказ, запланировано).
Интеграция с AmoCRM / Bitrix24 через API.
📌 Технические требования:

Синхронизация в реальном времени.
4. Авто-прогрев клиентов
📌 Задачи:

Авто-отправка WhatsApp, email, SMS.
Настройка касательных точек (3-5 напоминаний).
Персонализированные сообщения.
📌 Технические требования:

Интеграция с WhatsApp API.
Подключение SMTP для email-рассылок.
5. Аналитика звонков
📌 Задачи:

Транскрибация звонков (Whisper API).
Анализ ключевых слов (AI-анализ).
Визуализация данных в Power BI.
📌 Технические требования:

Сохранение всех транскрипций в базе.
6. Личный кабинет клиента
📌 Функционал:

Добавление номеров клиентов.
Просмотр статистики звонков.
Настройка скриптов звонков.
Управление оплатой подписки.
📌 Технические требования:

Разработка на React.js / Vue.js.
7. Панель администратора
📌 Функционал:

Мониторинг звонков в реальном времени.
Управление пользователями.
Настройка тарифных планов.
📌 Технические требования:

Доступ через JWT-аутентификацию.
